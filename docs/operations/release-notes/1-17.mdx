UDS Core 1.17 adds a CSS-only classification banner mode and improves Pepr admission webhook reliability. The release updates Keycloak to 26.8.2 through an automated upgrade.

### ⚠ Breaking changes

| Change | Impact | Action required |
| --- | --- | --- |
| Keycloak 26.8.2 upgrade | Authentication may be intermittent for a few minutes during the upgrade. | Plan for a brief authentication interruption. Core handles the transition automatically. |

### Notable features

This release includes these features and fixes:

- **CSS-only classification banners:** Set `cssOnly: true` on a `classificationBanners` entry to keep the page body unchanged. This mode supports server-rendered applications that remove injected banner elements during hydration. A Content Security Policy that blocks inline styles can prevent the banner from appearing. See [Enable the classification banner](/how-to-guides/platform-features/enable-classification-banner/) ([#3095](https://github.com/defenseunicorns/uds-core/pull/3095)).
- **Pepr admission webhook reliability:** Fixes webhook connection resets that could occur while Istio CNI updates the inbound traffic path for Pepr admission pods ([#3199](https://github.com/defenseunicorns/uds-core/pull/3199)).
- **Keycloak upgrade compatibility:** Updates Keycloak to 26.8.2 and renews rejected Admin API credentials during the automated upgrade ([#3207](https://github.com/defenseunicorns/uds-core/pull/3207)).
- **Grafana profile privacy:** Disables Gravatar profile image requests by default, so Grafana does not contact Gravatar to look up profile images ([#3203](https://github.com/defenseunicorns/uds-core/pull/3203)).
- **Gateway TLS certificates:** Rotates the tenant and admin gateway certificates ([#3201](https://github.com/defenseunicorns/uds-core/pull/3201)).

## Upgrade considerations

### Identity Config updates (0.32.6)

UDS Core updates UDS Identity Config from 0.32.4 to [0.32.6](https://github.com/defenseunicorns/uds-identity-config/releases/tag/v0.32.6). This version includes Keycloak 26.8.2 compatibility updates and restores passwordless credential registration. Core applies the upgrade automatically. See the [UDS Identity Config 0.32.6 changelog](https://github.com/defenseunicorns/uds-identity-config/blob/main/CHANGELOG.md#0326-2026-11-09).
