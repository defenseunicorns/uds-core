UDS Core 1.16 improves operator stability and includes a fix for cross-namespace Keycloak client ownership. UDS Portal adds Helm values for scheduling and additional environment variables.

### Notable features

This release includes these features and fixes:

- **Operator stability:** Improves ambient egress waypoint lifecycle and resource cleanup, and keeps reconciliation status updates working when Kubernetes event writes fail ([#3007](https://github.com/defenseunicorns/uds-core/pull/3007), [#3008](https://github.com/defenseunicorns/uds-core/pull/3008)).
- **Keycloak client ownership fix:** Prevents cross-namespace client ownership bypass by rejecting collisions with generated Authservice probe client IDs. Also available in UDS Core 1.15.2 ([#3101](https://github.com/defenseunicorns/uds-core/pull/3101)).
- **Portal Helm values:** UDS Portal 0.6.0 adds `nodeSelector`, `affinity`, `tolerations`, and `extraEnvs` for Pod placement and additional environment variables. Configure them through [Zarf Values or bundle overrides](/concepts/configuration-and-packaging/package-values/) ([#3161](https://github.com/defenseunicorns/uds-core/pull/3161)).
