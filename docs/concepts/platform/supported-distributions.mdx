UDS Core requires Kubernetes **1.36 or newer** with the native validating and mutating admission v1 APIs enabled. Upgrade the cluster before upgrading Core; older Kubernetes versions have no compatibility mode. The following [CNCF-conformant distributions](https://www.cncf.io/training/certification/software-conformance/) are actively tested in CI:

> [!NOTE]
> UDS Core tests EKS, AKS, and RKE2 against **Kubernetes 1.36**. The target is typically **n-1** (one minor version behind the latest release, latest patch). This version may lag slightly behind new Kubernetes releases.

| Distribution | K8s Version | Status | Testing Schedule |
|-------------|-------------|--------|-----------------|
| [K3s](https://k3s.io/) / [k3d](https://k3d.io/) | **1.36**, **1.37** | [![Kubernetes Compatibility](https://github.com/defenseunicorns/uds-core/actions/workflows/test-kubernetes-matrix.yaml/badge.svg?branch=main&event=schedule)](https://github.com/defenseunicorns/uds-core/actions/workflows/test-kubernetes-matrix.yaml?query=event%3Aschedule+branch%3Amain) | Nightly, on demand, and when pull requests change the controller, API, base package, or compatibility workflow |
| [K0s](https://k0sproject.io/) | **1.37** | [![K0s Test](https://github.com/defenseunicorns/uds-core/actions/workflows/test-k0s.yaml/badge.svg?branch=main&event=schedule)](https://github.com/defenseunicorns/uds-core/actions/workflows/test-k0s.yaml?query=event%3Aschedule+branch%3Amain) | Nightly and on qualifying pull requests |
| [Amazon EKS](https://aws.amazon.com/eks/) | **1.36** | [![EKS Test](https://github.com/defenseunicorns/uds-core/actions/workflows/test-eks.yaml/badge.svg?branch=main&event=schedule)](https://github.com/defenseunicorns/uds-core/actions/workflows/test-eks.yaml?query=event%3Aschedule+branch%3Amain) | Weekly and before each release |
| [Azure AKS](https://azure.microsoft.com/en-us/products/kubernetes-service) | **1.36** | [![AKS Test](https://github.com/defenseunicorns/uds-core/actions/workflows/test-aks.yaml/badge.svg?branch=main&event=schedule)](https://github.com/defenseunicorns/uds-core/actions/workflows/test-aks.yaml?query=event%3Aschedule+branch%3Amain) | Weekly and before each release |
| [RKE2](https://github.com/rancher/rke2) (on AWS) | **1.36** | [![RKE2 Test](https://github.com/defenseunicorns/uds-core/actions/workflows/test-rke2.yaml/badge.svg?branch=main&event=schedule)](https://github.com/defenseunicorns/uds-core/actions/workflows/test-rke2.yaml?query=event%3Aschedule+branch%3Amain) | Weekly and before each release |

> [!NOTE]
> Amazon EKS CI currently uses a non-FIPS Bottlerocket AMI and does not validate FIPS node operating system compatibility. This temporary coverage gap avoids the [`registry1` Bottlerocket FIPS compatibility issue](/concepts/platform/flavors/#bottlerocket-fips-compatibility).

> [!NOTE]
> Unlisted CNCF-conformant distributions are expected to work but are not validated in CI. Bug reports and contributions for compatibility issues are welcome.

Regular pull request tests use the default K3s version in the [setup task](https://github.com/defenseunicorns/uds-core/blob/main/tasks/setup.yaml). The [Kubernetes compatibility workflow](https://github.com/defenseunicorns/uds-core/blob/main/.github/workflows/test-kubernetes-matrix.yaml) tests exact K3s releases. This workflow does not define the UDS Core support policy. Kubernetes release support is tracked by the [Kubernetes release calendar](https://kubernetes.io/releases/).
