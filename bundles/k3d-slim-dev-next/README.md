# UDS Core K3d slim dev bundle - CLI Next

This directory contains the UDS CLI Next source for the K3d slim dev demo bundle.

- `bundle.uds.hcl` defines the published `k3d-core-slim-dev-next` bundle.
- `defaults.uds.hcl` contains bundle defaults.
- `values/` contains templated Zarf values for functional layer packages.

The Legacy bundle source remains in `bundles/k3d-slim-dev/`.
