# Documentation authoring

Use this skill for documentation work in this repository.

## Before writing

Read:

- `docs/dev/style-rules.md`
- `docs/dev/voice-profile.md`
- The reference for the document type:
  - `references/release-notes-template.md`
  - `references/how-to-guide-template.md`
  - `references/troubleshooting-runbook-template.md`
  - `references/reference-page-template.md`

Use the template that matches the page's purpose. Apply the repository style and voice rules to every documentation change, including pages that do not use a template.

## Before delivering

Review the changed documentation against the relevant template and the quick checklist in `docs/dev/style-rules.md`. Verify internal links, commands, configuration paths, and examples against the source files they describe.
